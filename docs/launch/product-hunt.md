# Product Hunt draft (do not publish until approved)

**Name:** Computer Monitor Dashboard

**Tagline (60 characters or fewer):**
RGB Windows hardware monitor for CPU, GPU, RAM, and storage

**Description:**
Computer Monitor Dashboard is a local Windows app that shows live CPU, GPU, RAM, VRAM, and storage use, plus temperatures when your hardware actually exposes them. Missing sensors show N/A instead of made-up numbers.

It includes a full RGB dashboard, a floating Bar/Mini overlay with Always on Top and click-through, and a desktop-background view. Sensor data stays on your PC. Download the Windows x64 installer from GitHub Releases—no development tools required.

**Link:**
https://github.com/mk-softwars/Computer-Monitor-Dashbaord/releases/latest
