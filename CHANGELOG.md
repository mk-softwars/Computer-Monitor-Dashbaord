# Changelog

## 1.1.1

Public Windows installer with Settings → Appearance, Original RGB / 90s /
Coding themes, and live Ethernet/Wi-Fi download and upload on the full
dashboard. Existing v1.0.0 saved settings keep those features visible. See
[release notes](docs/RELEASE_NOTES.md).

## 1.1.0

Live Ethernet/Wi-Fi download and upload speed in Mbps, plus Original RGB, 90s,
and Coding themes.

## 1.0.0

First public Windows release: local CPU, GPU, RAM, VRAM, and storage
monitoring, Full/Windowed/Bar/Mini/Desktop modes, Always on Top, overlay
opacity, and Click-Through.
